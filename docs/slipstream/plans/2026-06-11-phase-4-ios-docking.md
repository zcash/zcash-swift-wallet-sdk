**Architecture (D4, D7, D8):**

1. **FFI surface** (`rust/src/lib.rs`): `zcashlc_slipstream_open`, `zcashlc_slipstream_start`, `zcashlc_slipstream_stop`, `zcashlc_slipstream_snapshot`, `zcashlc_slipstream_drain_events`, `zcashlc_slipstream_free`. Handle pattern = `*mut SlipstreamHandle` (Box::into_raw); poll-based per D8. The handle owns a `tokio::runtime::Runtime` + `slipstream_core::engine::sync_once` invocation loop. Engine lifecycle: open allocates handle, start spawns sync task, stop cancels it, snapshot/drain_events reads atomics/ring, free drops box. Mirrors the `TorRuntime` FFI pattern (`rust/src/lib.rs:3157-3194`).
2. **Cargo feature gate**: `slipstream` feature in `slipstream-core` Cargo.toml guards the engine's tokio runtime and the new FFI glue from being compiled into the plain static lib target (where tokio multi-thread conflicts with libzcashlc's async surface). Slipstream's tokio runtime is independent of arti's `PreferredRuntime` (Tor precedent at `tor.rs:36-47`).
3. **XCFramework build**: the existing `Scripts/init-local-ffi.sh` (`--macos-only` for dev, all arches for release) already builds `libzcashlc.xcframework`. Adding new `#[no_mangle] pub unsafe extern "C" fn zcashlc_slipstream_*` functions in `rust/src/lib.rs` automatically includes them in the XCFramework on the next build. The C header (`zcashlc.h`) is generated by cbindgen (run automatically in the `FFIBuilder` Xcode target) — the new `SlipstreamHandle` opaque type + function declarations appear automatically.
4. **Swift wrapper** (`Sources/ZcashLightClientKit/Slipstream/SlipstreamEngine.swift`): a Swift actor that wraps `*mut SlipstreamHandle`, mirrors `TorClient.swift` (lazy init, `deinit` → `free`, explicit `start`/`stop`). Exposes `start(ufvk:birthday:server:walletDir:)` → `zcashlc_slipstream_start`; `stop()` → `zcashlc_slipstream_stop`; `latestSnapshot() → SlipstreamSnapshot` → `zcashlc_slipstream_snapshot`; `drainEvents() → [SlipstreamEvent]` → `zcashlc_slipstream_drain_events`. Periodic polling: `SlipstreamEngine` has a 2s `AsyncTimerSequence` task (T4.3).
5. **Swift seam** (`SlipstreamSynchronizer: Synchronizer`): implements ~10 sync members on `SlipstreamEngine`; delegates ALL ~40 data-model members (`transactions`, `getAccountsBalances`, etc.) to the existing `TransactionRepository` / `ZcashRustBackend` via the same `DIContainer` that `SDKSynchronizer` uses. This is possible because both synchronizers write to the SAME `data.db` — `zcash_client_sqlite` is the DB in both cases. **No data model change (D3).**
6. **Zodl integration** (T4.5): `slipstream` branch on `/Users/lukaskorba/Dev/Xcode/GitHub/LukasKorba/secant-ios-wallet`, cut from Zodl's `main`. Add `SlipstreamSynchronizer` behind `DEBUG_USE_SLIPSTREAM=true` env variable; run both sync paths with the same seed; record M1 checklist.

**SeedRequired landmine (P4 gate Blocker):** When `WalletSession::open` calls `init_wallet_db(None)`, if the existing `data.db` has pending migrations that require the seed, it returns `WalletMigrationError::SeedRequired`. For Zodl's EXISTING wallet opened by the old SDK: if the user has already migrated via the old SDK (normal operation), `init_wallet_db(None)` will NOT need the seed. Slipstream always opens with `None` seed (keyless — D6). The landmine only triggers for a database that has NEVER been opened by the old SDK at the new migration level. Mitigation: pre-open the database via the old SDK's `SDKSynchronizer.prepare()` before enabling Slipstream; Zodl's `AppDelegate` already does this on launch. Record in T4.5 verification.

### Task 4.1: FFI handle + Rust-side functions

**Goal:** A minimal, correct `zcashlc_slipstream_*` FFI surface that can be exercised by a Rust-side test before any Swift is written.

**Step 1: Create `slipstream/core/src/ffi_handle.rs`**

```rust
//! Opaque FFI handle for the Slipstream engine.
//!
//! Lifecycle:
//!   open  → allocates SlipstreamHandle (tokio runtime + channel + snapshot atomics + event ring)
//!   start → spawns sync task on the runtime; previous task cancelled first
//!   stop  → cancels the sync task; handle stays live for snapshot/drain_events
//!   free  → drops the handle (drops runtime → all tasks cancel)
//!
//! All fields are Send + Sync; the handle is always behind a raw pointer (Box::into_raw),
//! accessed from Swift/Obj-C single-threaded callers serialised by the actor.
//!
//! BINDING: SlipstreamHandle is NOT exposed in the C header (opaque pointer). Its fields
//! are internal. The C header only sees `typedef struct SlipstreamHandle SlipstreamHandle;`.

use std::sync::{Arc, Mutex};
use tokio::{runtime::Runtime, task::JoinHandle};

use crate::{
    config::Endpoint,
    events::Progress,
};

/// C-compatible snapshot struct. All fields are C-safe integers.
/// Maps to `FfiSlipstreamSnapshot` in `zcashlc.h` (cbindgen generates this).
#[repr(C)]
#[derive(Debug, Default, Clone, Copy)]
pub struct FfiSlipstreamSnapshot {
    /// Current chain tip height (0 = not yet fetched).
    pub chain_tip: u64,
    /// Number of blocks fetched in the current/last sync pass.
    pub fetched_blocks: u64,
    /// Number of blocks scanned in the current/last sync pass.
    pub scanned_blocks: u64,
    /// Number of transactions enhanced in the current/last sync pass.
    pub enhanced_txs: u64,
    /// End height of the block range currently being processed.
    pub current_range_end: u64,
    /// Sync state: 0=idle, 1=syncing, 2=error, 3=done.
    pub state: u8,
}

/// C-compatible event record.
#[repr(C)]
#[derive(Debug, Clone, Copy)]
pub struct FfiSlipstreamEvent {
    /// Event tag: 1=SyncStarted, 2=SyncProgress, 3=SyncDone, 4=SyncError, 5=FoundTransactions.
    pub tag: u8,
    /// For FoundTransactions: count of transactions found; for SyncDone: 0; for SyncError: error code.
    pub value: u64,
}

/// State of the sync task.
#[derive(Debug, Clone, Copy, PartialEq)]
pub enum SyncState {
    Idle,
    Syncing,
    Error(u8), // error code (u8 for C compat)
    Done,
}

/// Maximum events to keep in the ring before dropping oldest.
const EVENT_RING_CAP: usize = 64;

pub struct SlipstreamHandle {
    /// Single multi-thread tokio runtime owned by this handle (dropped with the handle).
    pub runtime: Runtime,
    /// Shared progress atomics — read by snapshot; written by the sync task.
    pub progress: Arc<Progress>,
    /// Current sync state — written by sync task, read by snapshot.
    pub state: Arc<Mutex<SyncState>>,
    /// Event ring — sync task pushes; Swift drains.
    pub events: Arc<Mutex<Vec<FfiSlipstreamEvent>>>,
    /// Join handle for the currently-running sync task (None = not started).
    pub task: Option<JoinHandle<()>>,
    /// Server endpoint — set at open; used for start.
    pub endpoint: Endpoint,
    /// Wallet db path — set at open.
    pub wallet_db_path: std::path::PathBuf,
    /// Network (0=mainnet, 1=testnet).
    pub network: zcash_protocol::consensus::Network,
}

impl SlipstreamHandle {
    pub fn push_event(&self, event: FfiSlipstreamEvent) {
        let mut ring = self.events.lock().unwrap_or_else(|p| p.into_inner());
        if ring.len() >= EVENT_RING_CAP {
            ring.remove(0); // drop oldest
        }
        ring.push(event);
    }

    pub fn snapshot(&self) -> FfiSlipstreamSnapshot {
        let p = &self.progress;
        let state = self.state.lock().unwrap_or_else(|p| p.into_inner());
        let state_u8 = match *state {
            SyncState::Idle => 0,
            SyncState::Syncing => 1,
            SyncState::Error(_) => 2,
            SyncState::Done => 3,
        };
        FfiSlipstreamSnapshot {
            chain_tip: p.chain_tip(),
            fetched_blocks: p.fetched_blocks(),
            scanned_blocks: p.scanned_blocks(),
            enhanced_txs: p.enhanced_txs(),
            current_range_end: p.current_range_end(),
            state: state_u8,
        }
    }
}
```

```rust
// ── Slipstream FFI surface ────────────────────────────────────────────────

use slipstream_core::ffi_handle::{FfiSlipstreamEvent, FfiSlipstreamSnapshot, SlipstreamHandle};

/// Opens a Slipstream engine handle.
/// - `db_data`/`db_data_len`: path to data.db (UTF-8 bytes).
/// - `server_host`/`server_host_len`: lightwalletd hostname (UTF-8 bytes).
/// - `server_port`: lightwalletd port.
/// - `use_tls`: 1 for TLS (mainnet), 0 for plaintext.
/// - `network_id`: 1 for mainnet, 0 for testnet.
///
/// Returns an opaque handle pointer, or null on failure.
/// Free with `zcashlc_slipstream_free` when done.
#[unsafe(no_mangle)]
pub unsafe extern "C" fn zcashlc_slipstream_open(
    db_data: *const u8, db_data_len: usize,
    server_host: *const u8, server_host_len: usize,
    server_port: u16, use_tls: bool,
    network_id: u32,
) -> *mut SlipstreamHandle {
    let res = catch_panic(|| {
        let db_path = Path::new(OsStr::from_bytes(unsafe { slice::from_raw_parts(db_data, db_data_len) }));
        let host = std::str::from_utf8(unsafe { slice::from_raw_parts(server_host, server_host_len) })
            .map_err(|e| anyhow::anyhow!("server_host UTF-8: {e}"))?;
        let network = if network_id == 1 { MainNetwork } else { TestNetwork };

        let runtime = tokio::runtime::Builder::new_multi_thread()
            .worker_threads(4)
            .enable_all()
            .build()
            .map_err(|e| anyhow::anyhow!("tokio runtime: {e}"))?;

        let handle = SlipstreamHandle {
            runtime,
            progress: Arc::new(slipstream_core::events::Progress::default()),
            state: Arc::new(std::sync::Mutex::new(slipstream_core::ffi_handle::SyncState::Idle)),
            events: Arc::new(std::sync::Mutex::new(Vec::new())),
            task: None,
            endpoint: slipstream_core::config::Endpoint {
                host: host.to_string(),
                port: server_port as u16,
                tls: use_tls,
            },
            wallet_db_path: db_path.to_path_buf(),
            network,
        };

        Ok(Box::into_raw(Box::new(handle)))
    });
    unwrap_exc_or_null(res)
}

/// Starts a sync pass.
/// - `ufvk`/`ufvk_len`: UFVK string (UTF-8 bytes), or null/0 for keyless update (birthday ignored).
/// - `birthday_height`: wallet birthday height (ignored when ufvk is null).
///
/// Can be called after stop() to restart. Cancels any in-flight sync first.
/// Returns true on success, false on error (check `zcashlc_get_last_error_message`).
#[unsafe(no_mangle)]
pub unsafe extern "C" fn zcashlc_slipstream_start(
    handle: *mut SlipstreamHandle,
    ufvk: *const u8, ufvk_len: usize,
    birthday_height: u64,
) -> bool {
    let res = catch_panic(|| {
        let handle = unsafe { handle.as_mut().ok_or_else(|| anyhow::anyhow!("null handle"))? };

        // Cancel any in-flight task.
        if let Some(task) = handle.task.take() {
            task.abort();
        }
        *handle.state.lock().unwrap() = slipstream_core::ffi_handle::SyncState::Syncing;

        let ufvk_str: Option<String> = if ufvk.is_null() || ufvk_len == 0 {
            None
        } else {
            Some(std::str::from_utf8(unsafe { slice::from_raw_parts(ufvk, ufvk_len) })
                .map_err(|e| anyhow::anyhow!("ufvk UTF-8: {e}"))?.to_string())
        };

        let cfg = slipstream_core::config::EngineConfig::new(
            handle.network,
            handle.wallet_db_path.clone(),
            handle.endpoint.clone(),
        );

        let ufvk_arg: Option<(String, u64)> = ufvk_str.map(|s| (s, birthday_height));
        let progress = Arc::clone(&handle.progress);
        let state = Arc::clone(&handle.state);
        let events = Arc::clone(&handle.events);

        // Spawn the sync task on the handle's runtime.
        let task = handle.runtime.spawn(async move {
            // Notify start.
            {
                let mut ring = events.lock().unwrap_or_else(|p| p.into_inner());
                ring.push(FfiSlipstreamEvent { tag: 1, value: 0 }); // SyncStarted
            }

            let result = slipstream_core::engine::sync_once(
                &cfg,
                ufvk_arg.as_ref().map(|(s, h)| (s.as_str(), *h)),
                Some(progress),
            ).await;

            match result {
                Ok(outcome) => {
                    *state.lock().unwrap() = slipstream_core::ffi_handle::SyncState::Done;
                    let mut ring = events.lock().unwrap_or_else(|p| p.into_inner());
                    ring.push(FfiSlipstreamEvent { tag: 3, value: outcome.enhance.txs_stored }); // SyncDone
                }
                Err(err) => {
                    tracing::error!(%err, "slipstream sync failed");
                    *state.lock().unwrap() = slipstream_core::ffi_handle::SyncState::Error(1);
                    let mut ring = events.lock().unwrap_or_else(|p| p.into_inner());
                    ring.push(FfiSlipstreamEvent { tag: 4, value: 1 }); // SyncError
                }
            }
        });

        handle.task = Some(task);
        Ok(true)
    });
    unwrap_exc_or(res, false)
}

/// Stops any in-flight sync. Returns true immediately (non-blocking — task abort is async).
#[unsafe(no_mangle)]
pub unsafe extern "C" fn zcashlc_slipstream_stop(handle: *mut SlipstreamHandle) -> bool {
    let res = catch_panic(|| {
        let handle = unsafe { handle.as_mut().ok_or_else(|| anyhow::anyhow!("null handle"))? };
        if let Some(task) = handle.task.take() {
            task.abort();
        }
        *handle.state.lock().unwrap() = slipstream_core::ffi_handle::SyncState::Idle;
        Ok(true)
    });
    unwrap_exc_or(res, false)
}

/// Reads a snapshot of current progress atomics (non-blocking, poll-based — D8).
/// Returns a zero-filled struct on null handle.
#[unsafe(no_mangle)]
pub unsafe extern "C" fn zcashlc_slipstream_snapshot(
    handle: *const SlipstreamHandle,
) -> FfiSlipstreamSnapshot {
    let res = catch_panic(|| {
        let handle = unsafe { handle.as_ref().ok_or_else(|| anyhow::anyhow!("null handle"))? };
        Ok(handle.snapshot())
    });
    unwrap_exc_or(res, FfiSlipstreamSnapshot::default())
}

/// Drains all queued events into a caller-allocated buffer.
/// - `buf`: caller-allocated array of `FfiSlipstreamEvent`.
/// - `buf_len`: length of the buffer (max events to drain).
/// Returns the number of events written (≤ buf_len).
///
/// # Safety
/// `buf` must be valid for writes for `buf_len` elements of `FfiSlipstreamEvent`.
#[unsafe(no_mangle)]
pub unsafe extern "C" fn zcashlc_slipstream_drain_events(
    handle: *mut SlipstreamHandle,
    buf: *mut FfiSlipstreamEvent,
    buf_len: usize,
) -> usize {
    let res = catch_panic(|| {
        let handle = unsafe { handle.as_mut().ok_or_else(|| anyhow::anyhow!("null handle"))? };
        let mut ring = handle.events.lock().unwrap_or_else(|p| p.into_inner());
        let to_copy = ring.len().min(buf_len);
        let drained: Vec<FfiSlipstreamEvent> = ring.drain(..to_copy).collect();
        unsafe { std::ptr::copy_nonoverlapping(drained.as_ptr(), buf, to_copy) };
        Ok(to_copy)
    });
    unwrap_exc_or(res, 0)
}

/// Frees a Slipstream handle. Cancels any in-flight sync and drops the tokio runtime.
///
/// # Safety
/// `handle` must be a pointer returned by `zcashlc_slipstream_open` and not yet freed.
#[unsafe(no_mangle)]
pub unsafe extern "C" fn zcashlc_slipstream_free(handle: *mut SlipstreamHandle) {
    if !handle.is_null() {
        let mut h: Box<SlipstreamHandle> = unsafe { Box::from_raw(handle) };
        // Abort in-flight task before dropping runtime (avoids panic on runtime drop with live tasks).
        if let Some(task) = h.task.take() {
            task.abort();
        }
        drop(h);
    }
}
```

```swift
// Sources/ZcashLightClientKit/Slipstream/SlipstreamFFI.swift
import Foundation
import libzcashlc

/// Swift-friendly wrapper around `FfiSlipstreamSnapshot` from the C header.
public struct SlipstreamSnapshot {
    public let chainTip: UInt64
    public let fetchedBlocks: UInt64
```

```swift
// Sources/ZcashLightClientKit/Slipstream/SlipstreamEngine.swift
import Foundation
import libzcashlc

/// Swift actor wrapping the Rust Slipstream engine handle.
/// Lifecycle mirrors TorClient (lazy open, explicit start/stop, deinit frees).
public actor SlipstreamEngine {
    private var handle: OpaquePointer?
    private let dbURL: URL
    private let server: LightWalletEndpoint

    public init(dbURL: URL, server: LightWalletEndpoint) {
        self.dbURL = dbURL
        self.server = server
    }

    deinit {
        if let h = handle {
            zcashlc_slipstream_free(h)
        }
    }

    // ── Lifecycle ──────────────────────────────────────────────────────────

    /// Opens the engine handle (lazy — call before start).
    public func open(network: NetworkType) throws {
        guard handle == nil else { return }
        let dbPath = dbURL.osPathStr()
        let host = server.host.asZcashlcStr()
        guard let h = zcashlc_slipstream_open(
            dbPath.0, dbPath.1,
            host.0, host.1,
            UInt16(server.port), server.requiresTLS,
            network == .mainnet ? 1 : 0
        ) else {
            throw ZcashError.rustSlipstreamOpen(lastErrorMessage(fallback: "open failed"))
        }
        handle = h
    }

    /// Starts a sync pass. Call `open` first.
    public func start(ufvk: String?, birthday: BlockHeight) throws {
        guard let h = handle else { throw ZcashError.rustSlipstreamNotOpen }
        let ufvkRaw = ufvk?.asZcashlcStr()
        guard zcashlc_slipstream_start(
            h,
            ufvkRaw?.0 ?? nil, ufvkRaw?.1 ?? 0,
            UInt64(birthday)
        ) else {
            throw ZcashError.rustSlipstreamStart(lastErrorMessage(fallback: "start failed"))
        }
    }

    /// Stops the in-flight sync (non-blocking abort).
    public func stop() {
        guard let h = handle else { return }
        _ = zcashlc_slipstream_stop(h)
    }

    // ── Poll surface (D8) ─────────────────────────────────────────────────

    /// Returns a snapshot of current progress counters (non-blocking).
    public func snapshot() -> SlipstreamSnapshot? {
        guard let h = handle else { return nil }
        let c = zcashlc_slipstream_snapshot(h)
        return SlipstreamSnapshot(c)
    }

    /// Drains queued events (non-blocking). Returns up to `capacity` events.
    public func drainEvents(capacity: Int = 64) -> [SlipstreamEngineEvent] {
        guard let h = handle else { return [] }
        var buf = [FfiSlipstreamEvent](repeating: FfiSlipstreamEvent(tag: 0, value: 0), count: capacity)
        let count = zcashlc_slipstream_drain_events(h, &buf, capacity)
        return buf.prefix(count).map { SlipstreamEngineEvent(tag: $0.tag, value: $0.value) }
    }
}
```

```swift
// Sources/ZcashLightClientKit/Slipstream/SlipstreamSynchronizer.swift
//
// Implements `Synchronizer` by:
//   - Sync members → SlipstreamEngine (start/stop/snapshot)
//   - Data members → TransactionRepository + ZcashRustBackend (same DIContainer as SDKSynchronizer)
//   - stateStream  → updated by 2s polling task during sync

import Foundation
import Combine

public final class SlipstreamSynchronizer: Synchronizer {
    public let alias: ZcashSynchronizerAlias

    // ── Sync engine ────────────────────────────────────────────────────────
    private let engine: SlipstreamEngine

    // ── Data delegation (D4) ──────────────────────────────────────────────
    private let initializer: Initializer
    private var transactionRepository: TransactionRepository {
        initializer.container.resolve(TransactionRepository.self)
    }

    // ── State subjects (mirrors SDKSynchronizer) ───────────────────────────
    private let stateSubject = CurrentValueSubject<SynchronizerState, Never>(.zero)
    private let eventSubject = PassthroughSubject<SynchronizerEvent, Never>()
    private let exchangeRateSubject = CurrentValueSubject<FiatCurrencyResult?, Never>(nil)

    public var latestState: SynchronizerState { stateSubject.value }
    public var connectionState: ConnectionState = .disconnected
    public var stateStream: AnyPublisher<SynchronizerState, Never> { stateSubject.eraseToAnyPublisher() }
    public var eventStream: AnyPublisher<SynchronizerEvent, Never> { eventSubject.eraseToAnyPublisher() }
    public var exchangeRateUSDStream: AnyPublisher<FiatCurrencyResult?, Never> { exchangeRateSubject.eraseToAnyPublisher() }

    // ── Polling ticker ────────────────────────────────────────────────────
    private var pollTask: Task<Void, Never>?

    public init(alias: ZcashSynchronizerAlias = .default, initializer: Initializer) {
        self.alias = alias
        self.initializer = initializer
        self.engine = SlipstreamEngine(
            dbURL: initializer.dataDbURL,
            server: initializer.endpoint
        )
    }

    // ── Synchronizer.prepare ──────────────────────────────────────────────
    public func prepare(
        with seed: [UInt8]?,
        walletBirthday: BlockHeight,
        for walletMode: WalletInitMode,
        name: String,
        keySource: String?
    ) async throws -> Initializer.InitializationResult {
        // Delegate full initialization to the existing Initializer (same as SDKSynchronizer).
        // This handles data.db migrations (including SeedRequired), UFVK import, and birthday setup.
        if case .seedRequired = try await initializer.initialize(
            with: seed, walletBirthday: walletBirthday, for: walletMode, name: name, keySource: keySource
        ) {
            return .seedRequired
        }
        // Open the engine handle.
        let network = initializer.network
        try await engine.open(network: network)
        return .success
    }

    // ── Synchronizer.start ────────────────────────────────────────────────
    public func start(retry: Bool = false) async throws {
        // Derive UFVK from the account already in data.db (Initializer stored it at prepare).
        // The Slipstream engine accepts ufvk=None for keyless updates (just updates chain tip / enhance queue).
        // For a full sync: pass the stored UFVK. The account is already imported in data.db from prepare.
        // Passing ufvk=None: engine calls ensure_account only when Some, so the account is NOT re-imported
        // on each start() call (idempotent — the account already exists in data.db).
        // BINDING: decide at T4.3 time whether to pass ufvk=Some (triggers ensure_account — idempotent,
        // just returns if already present) or None (skips ensure_account). Prefer None after prepare,
        // because birthday treestate is fetched at prepare time and stored.
        let birthday = BlockHeight(initializer.walletBirthday)
        try await engine.start(ufvk: nil, birthday: birthday)
        startPolling()
        stateSubject.send(SynchronizerState(
            syncSessionID: UUID(),
            accountsBalances: [:],
            internalSyncStatus: .syncing(0, false),
            latestBlockHeight: .zero
        ))
    }

    // ── Synchronizer.stop ────────────────────────────────────────────────
    public func stop() {
        engine.stop()
        stopPolling()
        stateSubject.send(SynchronizerState(
            syncSessionID: stateSubject.value.syncSessionID,
            accountsBalances: stateSubject.value.accountsBalances,
            internalSyncStatus: .stopped,
            latestBlockHeight: stateSubject.value.latestBlockHeight
        ))
    }

    // ── Polling task (D8) ─────────────────────────────────────────────────

    private func startPolling() {
        pollTask?.cancel()
        pollTask = Task {
            // Poll every 2 seconds; drain events and update stateSubject.
            while !Task.isCancelled {
                await self.tickPoll()
                try? await Task.sleep(nanoseconds: 2_000_000_000)
            }
        }
    }

    private func stopPolling() {
        pollTask?.cancel()
        pollTask = nil
    }

    @MainActor
    private func tickPoll() async {
        guard let snap = await engine.snapshot() else { return }
        let events = await engine.drainEvents()
        // Update state from snapshot.
        let progress = Float(snap.scannedBlocks) / Float(max(snap.chainTip, 1))
        let newStatus: InternalSyncStatus = {
            switch snap.state {
            case 0: return .disconnected
            case 1: return .syncing(min(progress, 1.0), false)
            case 2: return .error(.rustSlipstreamSyncFailed(snap.chainTip))
            case 3:
                // Sync done — fetch updated balances.
                return .synced
            default: return .disconnected
            }
        }()
        let balances = (try? await getAccountsBalances()) ?? [:]
        stateSubject.send(SynchronizerState(
            syncSessionID: stateSubject.value.syncSessionID,
            accountsBalances: balances,
            internalSyncStatus: newStatus,
            latestBlockHeight: BlockHeight(snap.chainTip)
        ))
        // Map SyncDone event → foundTransactions (query tx repo for new txs).
        for event in events where event.tag == 3 && event.value > 0 {
            let txs = (try? await allTransactions()) ?? []
            if !txs.isEmpty {
                eventSubject.send(.foundTransactions(txs, nil))
            }
        }
    }

    // ── Data members — all delegated ──────────────────────────────────────

    public func getAccountsBalances() async throws -> [AccountUUID: AccountBalance] {
        try await initializer.rustBackend.getWalletSummary()?.accountBalances ?? [:]
    }

    // ... all other Synchronizer protocol members delegate to transactionRepository
    // or initializer.rustBackend — see SDKSynchronizer.swift lines 547-617 for patterns.
    // T4.3 must implement ALL required protocol members (not shown here in full for brevity).
    // Use SDKSynchronizer as the implementation reference.
}
```
