The Slipstream Book

Audit-grade documentation for the Slipstream sync engine — architecture, hard problems, correctness evidence, security & privacy analysis, and the honest list of what is not done yet.

What this is

Slipstream is a greenfield Rust sync engine for Zcash mobile wallets. It keeps the proven upstream wallet logic (librustzcash) as its “brain” and replaces the orchestration “body”: parallel fetching, pipelined scanning, and an in-memory commitment-tree persistence path proven byte-identical to upstream’s by a golden-oracle harness. On a 2016 iPad it took a real wallet restore from 64 minutes to 8:30; every claim in this book traces to a measurement record or a line of code.

Reading honestly

This book documents gaps as plainly as achievements. Chapter 19 (and the “Known limitations” section closing most chapters) is the canonical list — including missing mempool detection, no in-foreground tip-following yet, and Tor not being wired into Slipstream’s network paths.
